# Ferrari Encyclopedia

A detailed, beginner-built website about Ferrari cars. Browse models, search, filter by engine type, sort by power or speed, and click any car to see its full specs: engine, power, 0-100 km/h, top speed, drivetrain, transmission and tires.

Built with plain **HTML, CSS and JavaScript**, with no frameworks.

## Features
- Hero section and responsive card layout (works on phones too)
- Live search by model name
- Filters: all, 12 cylinders, V8, hybrid
- Sort by newest, oldest, most powerful, fastest
- Pop-up detail view with power and speed bars

## Run it
Open `index.html` in any browser. That's it.

## Add your own photos
Put image files in an `images` folder, named after the car id, for example `images/f40.jpg` or `images/458-italia.jpg`. Cars without a photo show a styled placeholder.

## Add a new car
Open `script.js`, copy one car block inside the `cars` list, paste it after a comma, and change the values.

## Notes
Specifications are approximate factory figures and can differ by version and source. This is a fan project for learning and is not affiliated with Ferrari S.p.A.
